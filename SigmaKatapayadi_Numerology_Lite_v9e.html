First Letter — Varna Graha Mapping

The first sounding consonant of the name gives the Varna Graha — the planet of the opening syllable. It follows the Agni Purana varga grouping (seven consonant families, each ruled by one Graha). Vowels and matras at the start are skipped; the first real consonant is used.

The Sigma Katapayadi Method — 4 Rules

1. Right to Left: Segment the Hindi name into syllable clusters. Process from the rightmost cluster first. The last syllable gives the first digit in the string.

2. Conjuncts — last consonant only: In a conjunct like त्र, the first consonant त has a halant (्) and is dead — skip it. Only the final consonant र (which carries the vowel) contributes its digit value.

3. Standalone vowels = 0: If a cluster is a vowel not preceded by any consonant (like अ, इ, उ at word start), it gives digit 0. Example: अत्रि → अ = 0, रि = 2 → Sigma = 2 → Taurus.

4. Vowel matras ignored: The matra (ा ि ी ु ू े ो etc.) following a consonant carries no digit. The consonant alone determines the value.

Sigma: Sum all extracted digit values. Sigma is just the total — not the concatenated number. Then: Sigma mod 12 = Rashi index. Sigma mod 7 = Planet (7). Sigma mod 9 = Planet (9). Sigma mod 27 = Nakshatra.

Why forward only? The reverse of any digit string gives the same digit-sum (since addition is commutative: 2+5 = 5+2 = 7). The reverse is therefore always identical to the forward result and needs no separate calculation.

The Sigma Katapayadi (GoPada Padhathi) sums all consonant digit values of the name and divides by 12. The remainder identifies the Nama Rashi — the Name Sign. Test it against the natal chart using the 5 connection patterns:

1. Name Rashi IS the Lagna sign
2. Name Rashi is in trine (1/5/9) from Lagna
3. Name Rashi lord aspects/conjoins Lagnesha
4. Name Rashi dispositor connects to Lagna
5. Name Rashi lord is the Yogakaraka / strongest planet
